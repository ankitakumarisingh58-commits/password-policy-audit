1. Introduction

A password policy is a set of rules designed to protect user accounts and confidential information. This project reviews a sample password policy and recommends practical security improvements.

2. Comparison with NIST Guidance

Weak Rule Recommended Practice
Exactly 8 characters Use at least 15 characters for password-only authentication.
Mandatory character combinations Prioritise length and block common or compromised passwords.
Change every 30 days Change passwords when compromise is suspected or confirmed.
Password reuse allowed Use a unique password for every account.
Password managers prohibited Allow password managers and autofill.

Reference: NIST Digital Identity Guidelines

3. Weak Password Rules

Short Passwords

Short passwords can be easier to guess.

Frequent Password Changes

Frequent changes may encourage predictable password variations.

Password Reuse

A leaked password may allow attackers to access other accounts.

No Login Protection

Unlimited login attempts can make password guessing easier.

4. Improved Password Policy

  • Use at least 15 characters for password-only authentication.
  • Use a different password for every account.
  • Use a reputable password manager.
  • Enable multi-factor authentication (MFA).
  • Block common and compromised passwords.
  • Change passwords promptly if they are compromised.
  • Protect accounts against repeated login attempts.
  • Never share passwords or OTPs.

5. One-Page Staff Awareness Guide
